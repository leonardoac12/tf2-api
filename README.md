# TF2-API

Una API RESTful sencillo para la práctica Frontend, despliegue JSON para armas y cosméticos de Team Fortress 2, al estilo PokeAPI.

## Características

- 📦 Información detallada de armas
- 🎩 Datos de cosméticos y sombreros
- 🔍 Búsqueda y filtrado
- 📄 Paginación de resultados
- 🚀 Respuestas en formato JSON

## Endpoints Base

GET /tf2-api/weapons/{id}

GET /tf2-api/v1/cosmetics/{id}
